7. DEFINITION OF DONE / PROFESSIONAL ACCEPTANCE


A phase task is COMPLETE only if: (1) requirement and data dependency identified, reviewed and signed off; (2) implementation present in a versioned project; (3) unit + negative + integration tests are runnable from a clean environment and actually PASS; (4) fixtures have source, date, licensing and hash; (5) log captures cache mode and input snapshots; (6) regression against previous stable is tested on pinned data; (7) data-quality and safety hard fails produce INCOMPLETE/ERROR instead of fabricated confirmed signal; (8) rollback compatibility/migration and release manifest verifiable; (9) UI-1.0 golden verified without unauthorized visual changes; (10) owner/approval recorded and evidence linked in release log.
New status vocabulary: DRAFT_REQUIREMENT / SPECIFIED / IMPLEMENTED / UNIT_TESTED / INTEGRATED / MARKET_VALIDATED / RELEASE_CANDIDATE / RELEASED / ROLLED_BACK. Avoid ambiguous DONE and blanket 8/8 verified. Historical design POC remains PROTOTYPE_TESTED only.
